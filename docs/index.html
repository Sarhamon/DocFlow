04 고친 것

새 서식을 태우자 기존 코드가 세 군데서 걸렸습니다. 전부 서식 수가 늘어나야 드러나는 문제였습니다.

  • schema/form.py

    파일명 파서가 앵커 형식 (서식 5-05호) [앵커] 제목만 처리해서 AID·혁신의 [AID 서식 1-01~10호] 제목이 통째로 실패했습니다. 155개(80%)의 서식번호·사업명이 비어 있었습니다. _NAME_BRACKET_RE를 추가해 두 형식을 모두 받습니다.

  • extract_schema.py

    서식 목차·신구대조표 10건이 서식으로 섞여 들어와 수치를 부풀렸습니다. SKIP_WORDS로 제외합니다.

  • extract_schema.py

    구버전 개정본이 같은 서식 번호를 써서 출력 파일명이 겹쳤고, 10개가 덮어써져 사라졌습니다. 번호가 겹치면 파일명을 그대로 쓰도록 바꿔 183개 전부 보존합니다.

작업 중 잡은 것

제외어를 처음에 "신구대조표"로 뒀더니 (서식 2-06호) 계획서 신구대조표가 같이 걸렸습니다. 이건 사업 변경 시 쓰는 실제 서식이라 "서식 신구대조표"로 좁혔습니다. 제외 규칙이 조용히 진짜 데이터를 지우는 경우라 확인이 필요했습니다.
