### 1-2. LLM (EC2)

1. AWS 콘솔에서 EC2(g4dn.xlarge, 서울) **시작** → 퍼블릭 IP 확인
2. **보안 그룹 인바운드 SSH(22) 를 현장 IP 로 고친다** (지금은 집 IP 만 열려 있다. 안 고치면 SSH 가 멈춘다)
3. 키 권한 (처음 한 번):
   `icacls C:\.ssh\plus-ec2.pem /inheritance:r /grant:r "$($env:USERNAME):R"`
4. 터널 (창을 열어 둔다):
   `ssh -i C:\.ssh\plus-ec2.pem -N -L 11434:localhost:11434 ubuntu@<퍼블릭 IP>`
5. 확인: `curl http://127.0.0.1:11434/api/tags` 에 `exaone3.5:7.8b` 가 보이면 된다.
   관리자 화면 > 시스템 설정의 LLM 상태로도 본다(주소는 기본값 `http://127.0.0.1:11434` 그대로).
6. **예열**: 시연 전에 '글로 채우기'를 한 번 돌린다. 첫 호출은 모델을 올리느라 오래 걸린다.

## 3. 막혔을 때

| 증상 | 대응 |
|---|---|
| 글로 채우기가 'LLM 서버에 연결하지 못했다' | 터널 창 확인 → 안 되면 "직접 입력·확인 화면" 으로 설명하고 미리 만든 7-01 을 연다 |
| SSH 가 멈춤 (timeout) | 보안 그룹 인바운드의 IP 가 현장 IP 인지. 휴대폰 핫스팟이면 IP 가 바뀐다 |
| 글로 채우기가 오래 걸림 | 첫 호출(모델 올리기). 예열을 안 했으면 30초 이상 걸릴 수 있다 |
| 문서 만들기가 오래 걸리거나 '변환 실패' | 서버를 `DOCFLOW_CONVERTER=none` 으로 띄웠는지 |
| 받은 HWPX 가 한글에서 안 열림 | 미리 만든 문서로 넘어간다 (같은 경로로 만든 것) |

## 4. 질문 대비 (알려진 한계)

- **쪽 넘김**: 서식이 쪽 나눔 없이 이어지는 경우가 있어, 칸에 서식 예시보다 긴 글을 넣으면 뒤 내용이 다음 쪽으로 밀린다
  (예: 9-02 세세부과제명이 두 줄이 되면 빈 3쪽). 한글에서 글을 줄이거나 쪽을 조정한다.
- **'없는 경우 삭제' 절**(2-03 의 6-2·6-3 등)은 자동으로 지우지 않는다. 해당이 없으면 한글에서 지운다.
- **서식 안내 문구**(빨간·파란 글씨의 `※ …`, `주) …`)는 '본문 문구 바꾸기'에서 빈칸으로 바꿔 지운다.
- **HWP·PDF** 는 서버가 만들지 않는다. 받은 HWPX 를 한글에서 고쳐 PDF 로 낸다(운영 방침).
- **작성일·서명란**은 입력 칸이 아니라 본문 문구라 '본문 문구 바꾸기'로 채운다(단추로 바로 넣을 수 있다).
