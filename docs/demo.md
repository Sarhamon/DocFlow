# 시연 안내 (운영 사이트)

> 2026-11-10 노트북 로컬 시연은 끝났다. 받은 의견과 처리는 [`dev-roadmap.md` 7장](dev-roadmap.md#7-시연-피드백-2026-11-10).
> 이 문서는 **AWS 운영 사이트로 시연**하는 안내다(2026-11-13 갱신). 배포·자원 구성은 [`deploy-aws.md`](deploy-aws.md).

사이트: **<http://docflow-ysu.duckdns.org>** — HTTPS 가 없어 `http://` 까지 적는다(브라우저가 https 로 먼저 시도하면 안 열린다).
서버는 HWPX 만 만든다. 받은 파일을 한글로 열어 보여 준다. LLM(글로 채우기·본문 초안·정성 판정)은 같은 VPC 의 EC2 를 쓴다.

## 1. 준비 (시연 30분 전)

자원은 평소 꺼 두고, 학교 계정이 **매일 19시에 자동으로 끈다**. 시연 날 켠다. 명령은 모두 MFA 세션(`--profile mfa`, `deploy-aws.md` 2장)으로.

```bash
aws rds start-db-instance --profile mfa --db-instance-identifier docflow-db
aws ec2 start-instances --profile mfa --instance-ids i-09c4bdcd27aacab5a        # LLM
aws rds wait db-instance-available --profile mfa --db-instance-identifier docflow-db   # 5~10분
aws ecs update-service --profile mfa --cluster docflow --service docflow --desired-count 1   # RDS 가 뜬 뒤에
aws ecs wait services-stable --profile mfa --cluster docflow --services docflow
```

1. <http://docflow-ysu.duckdns.org/api/health> 가 `{"ok":true,...}` 이면 된다. 새 태스크 IP 가 DuckDNS 에 퍼지는 데 1분쯤 걸린다.
2. 로그인: 시연 계정 `sian`(시연용, 관리자 권한). 비밀번호는 따로 전달. 루트는 `root`.
3. 관리자 > 시스템에서 LLM 이 **준비됨** 인지 본다(주소 `http://172.31.18.178:11434`, 모델 `exaone3.5:7.8b`). 아니면 **다시 확인**.
4. **예열**: '글로 채우기'를 한 번 돌린다. 첫 호출은 모델을 올리느라 30~40초, 그 뒤는 5~15초.
5. 시연 PC 브라우저에서 사이트를 한 번 **Ctrl+Shift+R** 로 새로 고친다(예전에 열어 본 PC 에 남은 옛 스크립트를 버린다).

서식(172종)·시연용 입력폼 설정·정성 판정 물음(7-01 회의비)은 이미 들어 있다.

## 2. 시연 순서 (약 10분)

| # | 보여 줄 것 | 서식 | 방법 |
|---|---|---|---|
| 1 | 로그인 → 서식 목록·검색 | — | `회의` 로 검색 → AID 7-01 회의계획서 → 서식 구조 미리보기 |
| 2 | **글로 채우기 → 확인 → 반영** | AID 7-01 회의계획서 (2쪽) | 새 문서 → 아래 글 붙여넣기 → 채운 값 확인 → '빈 칸만 채우기' |
| 3 | 오류 잡기 | 7-01 | 남은 오류(회의장소·참석 대상)를 눌러 그 칸으로 이동 → 입력. 산업체 명단은 '+ 행 추가' 로 3명 |
| 4 | 본문 문구 바꾸기 | 7-01 | '작성일을 오늘로' + '회의신청자 : ○ ○ ○' 를 이름으로 |

### 글로 채우기에 붙여 넣을 글 (7-01)

> 2026년 11월 17일 화요일 오후 3시부터 5시까지 본관 3층 대회의실에서 컴퓨터소프트웨어과 주관으로
> 2026년 산학협력 교육과정 운영위원회를 엽니다. 안건은 2027학년도 교육과정 개편안 검토, 가족회사 현장실습
> 운영 방안, 졸업생 채용 연계 협의입니다. 대학에서는 김연성, 이하늘, 박서준 교수가, 산업체에서는
> (주)한빛소프트 정민호 이사, 넥스트데이터(주) 최유진 팀장, (주)클라우드웍스 한도윤 책임연구원이 참석합니다.
> 회의비는 1인 30,000원씩 6명입니다.

결과는 늘 확인 후 반영한다(인용 경고가 뜬 칸은 원문에 없는 값). 모델이 회의장소·참석 대상을 빠뜨리기도 한다 — 3번에서 직접 채운다.

### 글로 채우기에 붙여 넣을 글 (1-02)

> [2026 AID] AI역량 심화교육 과제 결과를 보고합니다. 2026년 3월부터 11월까지 산학협력관 강의실에서
> 컴퓨터소프트웨어과 학생 40명을 대상으로 생성형 AI 활용 실습 12회를 운영했고, 수료생 36명 중 28명이
> 관련 자격증을 취득했습니다. 예산 12,000,000원 중 11,450,000원을 집행했습니다. 붙임은 과제 결과 보고서 1부입니다.

## 3. 막혔을 때

| 증상 | 대응 |
|---|---|
| 사이트가 안 열림 | `http://` 로 적었는지 → RDS 가 `available` 인지(`aws rds describe-db-instances …`) → ECS `runningCount` 가 1 인지. 19시 이후면 자동으로 꺼진 것 |
| 새 태스크가 떴는데도 안 열림 | DuckDNS 가 새 IP 로 바뀌는 데 1분쯤. `nslookup docflow-ysu.duckdns.org` 로 확인 |
| 단추를 눌러도 반응이 없거나 스크립트 오류 | Ctrl+Shift+R (배포 전 스크립트가 캐시에 남은 경우) |
| 글로 채우기가 'LLM 서버에 연결하지 못했다' | EC2 가 켜졌는지 → 관리자 > 시스템 '다시 확인'. 안 되면 직접 입력으로 설명하고 완료본 #14 를 연다 |
| 글로 채우기가 오래 걸림 | 첫 호출(모델 올리기). 예열을 안 했으면 30초 이상 걸릴 수 있다 |
| 받은 HWPX 가 한글에서 안 열림 | 완료본 #14 의 HWPX 로 넘어간다 |

## 4. 질문 대비 (알려진 한계)

- **쪽 넘김**: 서식이 쪽 나눔 없이 이어지는 경우가 있어, 칸에 서식 예시보다 긴 글을 넣으면 뒤 내용이 다음 쪽으로 밀린다
  (예: 9-02 세세부과제명이 두 줄이 되면 빈 3쪽). 한글에서 글을 줄이거나 쪽을 조정한다.
- **'없는 경우 삭제' 절**(2-03 의 6-2·6-3 등)은 자동으로 지우지 않는다. 해당이 없으면 한글에서 지운다.
- **서식 안내 문구**(빨간·파란 글씨의 `※ …`, `주) …`)는 '본문 문구 바꾸기'에서 빈칸으로 바꿔 지운다.
- **HWP·PDF** 는 서버가 만들지 않는다. 받은 HWPX 를 한글에서 고쳐 PDF 로 낸다(운영 방침).
- **작성일·서명란**은 입력 칸이 아니라 본문 문구라 '본문 문구 바꾸기'로 채운다(단추로 바로 넣을 수 있다).
- **LLM 결과**는 칸을 빠뜨리거나 숫자를 틀릴 수 있다. 그래서 늘 확인 후 반영하고, 글에 없는 값은 경고로 표시한다.

## 5. 끝나면

```bash
aws ecs update-service --profile mfa --cluster docflow --service docflow --desired-count 0
aws ec2 stop-instances --profile mfa --instance-ids i-09c4bdcd27aacab5a
aws rds stop-db-instance --profile mfa --db-instance-identifier docflow-db
```
