글로 채우기

무엇을 하는지 적으면 LLM 이 칸을 채웁니다. 넣기 전에 확인합니다. 명단·계좌·주민등록번호는 LLM 에 넘기지 않습니다.

기본 항목

서식 입력

입력 칸필수자동·결재란

본문 문구 바꾸기

입력 칸이 아닌 본문에 남은 자리표시자(예: 20○○년 ○○월 ○○일)를 바꿀 문구로 바꿉니다.

검증 결과

규정 해석이 필요한 물음을 LLM 이 판정합니다
  • 입력하면 칸마다 바로 점검합니다. 다 채웠으면 [검증]을 누르세요.

연결 문서

이어 두면 두 문서의 금액을 견줘 다르면 경고합니다 (문서 만들기는 막지 않습니다).

만든 문서

입금계좌 확인서로 명단 채우기

학생이 낸 확인서의 글자를 그대로 옮깁니다 (LLM 을 거치지 않습니다). 넣기 전에 확인하세요.

본문 초안

채운 칸의 값으로 LLM 이 글을 씁니다. 금액·날짜·인원이 입력값에 없으면 경고합니다. 명단은 인원과 합계만 넘깁니다.

정성 판정 결과

LLM 의 판정이라 참고용입니다. 부적합·판단 불가는 검증 결과에 경고로 남고, 입력을 고치면 사라집니다. 근거를 누르면 그 칸으로 갑니다.

LLM 이 채운 값

글에 없는 금액·날짜는 경고로 표시합니다. 넣은 뒤에도 칸에서 고칠 수 있습니다.

문서 만들기

내려받을 형식을 고르세요. 한글 문서(HWPX)는 늘 함께 만듭니다.
